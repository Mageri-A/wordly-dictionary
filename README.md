# WORDLY DICTIONARY
A single page application that looks up English words using Free DictionaryAPI
## Features
- Search for word without reloading the page
- Pronunciation text, audio playback, definitions, examples and synonyms
- Save favorite words
- Light and dark theme toggle
- Error messages for empty input, unknown words and network failures
## Tech
- HTML, CSS, JavaScript
- API: https://dictionaryapi.dev
## Run
- Open index.html in a browser or use the IDE
## Future improvement
- Show word originand more than one audio accent
- Add a search history list
- Add keyboard shortcut to focus the search bar
